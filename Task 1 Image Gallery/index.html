About the Project

CodeAlpha Image Gallery is a modern, responsive frontend project built for the CodeAlpha Frontend Development Internship (Task 1). It demonstrates semantic HTML, advanced CSS (glassmorphism, gradients, responsive grid, dark mode), and vanilla JavaScript features including category filtering, real-time search, sort, favorites with localStorage, a full lightbox previewer with keyboard navigation, image download (Blob API), and Web Share.

  • ✅ 42 categories × 50 images = 2,100 unique topic-matched photos
  • ✅ Every image title is generated from its exact category subject
  • ✅ Multi-layer fallback so no image is ever broken
  • ✅ Responsive masonry-style grid (1 → 5 columns)
  • ✅ Dark mode + favorites saved across sessions
  • ✅ Lightbox with prev/next, keyboard shortcuts, share & download
