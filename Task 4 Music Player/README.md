# CodeAlpha Music Player

A modern, responsive music player web application inspired by popular music streaming interfaces. This project was developed as **Task 4** for the **CodeAlpha Frontend Development Internship**.

## Overview

CodeAlpha Music Player provides an interactive music-listening experience with essential playback controls, song search, playlists, favorites, recently played tracks, and customizable themes.

The application is designed with a clean interface and responsive layout so it can be used across desktop and mobile devices.

## Features

### Music Playback

- Play and pause songs
- Next and previous track controls
- Autoplay the next song
- Progress bar with playback control
- Volume control
- Shuffle mode
- Repeat mode
- Song duration display

### Song Information

- Song title
- Artist name
- Genre
- Cover image
- Track duration

### Search and Discovery

- Search songs by title
- Search songs by artist
- Browse songs by artist categories

### Playlists and Library

- Add songs to favorites
- Favorites playlist
- Create custom playlists
- Store playlists using `localStorage`
- Recently played songs
- Persistent favorites using `localStorage`

### User Interface

- Light mode
- Dark mode
- Responsive design
- Toast notifications
- Interactive controls
- Keyboard shortcuts

## Keyboard Shortcuts

| Key | Action |
|---|---|
| `Space` | Play / Pause |
| `Arrow Right` | Next Song |
| `Arrow Left` | Previous Song |
| `Arrow Up` | Increase Volume |
| `Arrow Down` | Decrease Volume |

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser `localStorage` API
